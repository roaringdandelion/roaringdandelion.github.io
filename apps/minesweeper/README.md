# Minesweeper Mini

A small, zero-dependency Minesweeper game built with browser-native HTML, CSS, and JavaScript.

## Run

Open `index.html` directly in a browser, or serve this folder with any static file server.

## Controls

- Left click reveals a tile.
- Right click places or removes a flag.
- The first reveal is always safe.
- Use the board selector to change difficulty.
- Each game starts with one extra life. It automatically saves you from your first mine hit.
- Each game also starts with one scanner. Reveal your first tile, activate Scanner, then choose a tile to inspect its 3 × 3 area.
